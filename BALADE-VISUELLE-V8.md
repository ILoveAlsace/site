# Balade visuelle V8

La V8 ajoute :

- une mosaïque animée sur la page d’accueil ;
- une page dédiée `#/balade-visuelle` ;
- un renouvellement progressif des images, une tuile à la fois ;
- un bouton de pause/reprise et un bouton de renouvellement immédiat ;
- un lien direct vers la réservation KE-Booking de l’hébergement sur chaque photographie ;
- le respect de `prefers-reduced-motion` ;
- une mise en page responsive en puzzle sur ordinateur, tablette et téléphone.

Le système utilise uniquement les photographies vérifiées et attribuées à leur bon hébergement.
